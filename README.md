# Warung Kita Simulator — Prototype 0.1

Prototype awal game Android offline bertema warung tradisional Indonesia.

## Konsep yang sudah ditetapkan
- 3D low-poly dan ringan
- First-person
- Warung campuran kayu dan tembok
- Lingkungan permukiman padat Indonesia
- Target uji: Redmi Note 14 4G
- Offline; belum memakai server atau akun online

## Isi prototype saat ini
- Area lingkungan sederhana
- Bangunan warung dan rak
- Produk placeholder berbentuk kotak warna
- Kontrol gerak first-person melalui sentuhan layar
- Kontrol kamera dengan geser sisi kanan layar
- Tombol interaksi sederhana
- Kontrol keyboard/mouse tersedia untuk pengujian di editor

## Catatan penting
Ini adalah **kerangka prototype**, bukan game final dan belum berupa APK yang sudah diuji di perangkat.
Model barang masih placeholder; merek/kemasan lokal, pelanggan, kasir, stok, uang, dan progres akan ditambahkan pada tahap berikutnya.

## Membuka proyek
1. Ekstrak folder ini.
2. Buka `project.godot` menggunakan Godot 4.3 atau lebih baru.
3. Jalankan scene utama.

## Catatan Android
Untuk menghasilkan APK Android, proyek perlu dikonfigurasi dengan Android export template dan Android SDK/JDK yang cocok dengan versi Godot. Preset ekspor dan workflow build Android akan disiapkan setelah kerangka prototype ini diperiksa dan disesuaikan.
